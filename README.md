# Uyuyan Aslanın Horultu Çevirmeni

## Resmi Açıklama

Bu yazılım, uyuyan bir aslanın çıkardığı horultuları Türkçe resmi evrak diline çevirmek üzere geliştirilmiştir. Proje, bilimsel, kültürel ve idari açıdan hayati öneme sahiptir. Aslan uyanana kadar tüm kararlar bu çeviriler üzerinden yürütülecektir.

## Neden Bu Kadar Ciddi?

Çünkü horultu bir tesadüf değildir. Her "hrrrr" aslında bir genelgedir. Her "pırrr" bir tebligattır. Bunu anlamayanlar tarihi kaçırır.

## Kurulum

```bash
python3 horultu_cevirmeni.py
```

Başka bir şey gerekmez. Resmiyet yeterlidir.

## Kullanım

Program size horultu sorar. Siz yazarsınız veya Enter'a basarsınız. Komisyon 0.3 saniye düşünür (bu süre kısaltılamaz, yasaktır) ve size resmi bir cümle verir.

Örnek çıktı:

```
Kaynak horultu: hrrrr
Resmi tercüme : Kamuoyuna saygıyla duyurulur.
```

## Sıklıkla Sorulan Sorular

**Aslan gerçekten var mı?**  
Var. Şu anda uyuyor. Rahatsız etmeyiniz.

**Çeviriler doğru mu?**  
Komisyon doğru kabul etmiştir. İtiraz 15 gün içindedir.

**Neden Python?**  
Çünkü aslan JavaScript sevmez.

## Dipnot (kimse bakmaz)

Bazı horultuların sandık dışı anlamları olduğu iddia edilmiştir. Bu iddialar henüz resmi evraka geçmemiştir. Geçerse buraya yazmayız zaten.
